# Lead Scraper

*A lightweight tool that evaluates and scrapes websites based on defined performance and quality metrics.*

---

## Overview
Lead Scraper discovers potential leads by scanning websites, scoring them against your criteria (e.g., performance, accessibility, design signals), and exporting qualified results.

## Key Features
- Metrics-based site evaluation (performance, accessibility, design)
- Configurable thresholds and filters
- Clean export for outreach workflows
